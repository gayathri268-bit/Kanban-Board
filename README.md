# 📋 Kanban Board

A task management Kanban Board built with React, TypeScript and Tailwind CSS.

## ✨ Features
- Add, Edit and Delete tasks
- Drag and drop tasks between columns
- Search tasks
- Data saved using Local Storage
- Calendar date on each task card

## 🛠️ Tech Stack
- React
- TypeScript
- Tailwind CSS
- DnD Kit
- React Icons
- Vite
